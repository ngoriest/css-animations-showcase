 🎨 CSS Animations Showcase

A beginner-friendly collection of CSS animations to demonstrate the power of modern CSS.

 🌟 Live Demo

Just open `index.html` in any modern browser!

 🚀 Quick Start

1. Download or clone this repository

    git clone git@github.com:ngoriest/css-animations-showcase.git


2. Open the project

   cd css-animations-showcase


3. Run the project

   Simply double-click index.html

   Or use Live Server in VS Code

🐛 Common Issues & Solutions

 Animations not playing	-  Check if browser supports CSS animations
 Hover effects too fast	-  Adjust transition duration (0.3s works well)
 Layout breaks	-  Make sure to include box-sizing: border-box
